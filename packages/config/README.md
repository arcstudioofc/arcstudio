# ARC Studio


Bem-vindo ao projeto **@arcstudio/config**! Este é o repositório de build do ARC Studio.

> "ARC never forget" – ARC Studio ajuda você a construir código confiável, persistente e fácil de manter.

## Pré-requisitos

- Node.js (versão 21 ou superior recomendada)
- pnpm (gerenciador de pacotes rápido e eficiente para monorepos)

## Estrutura do Projeto

```
.
├── packages/           # Workspaces individuais (ex: core, ui, utils, etc.)
│   └── config/             # Pacote de configuração de build
│       ├── base.json
        └── build.preset.ts
```
