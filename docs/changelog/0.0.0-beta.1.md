## CHANGELOG

### 0.0.0-beta.1 — Bootstrap da Workspace

> Primeira versão pública da monorepo. Estrutura definida, pacotes versionados e base pronta para evolução.

#### ✨ Destaques

* Inicialização oficial da **workspace monorepo** com PNPM.
* Padronização de versionamento inicial entre pacotes.
* Integração com **Turborepo** para orquestração de builds e tarefas.
* Separação clara entre aplicações, serviços e utilitários.

#### 📦 Pacotes incluídos

| Pacote          | Versão         | Status                    |
| --------------- | -------------- | ------------------------- |
| `api`           | `0.1.0-beta`   | Backend inicial           |
| `apps/electron` | `0.1.0-beta`   | App desktop               |
| `web`           | `0.1.0-beta.2` | Frontend web              |
| `auth`          | `0.1.0`        | Módulo estável            |
| `scripts`       | `0.0.0`        | Utilitários internos      |
| `root`          | `0.0.0-beta.1` | Configuração da workspace |

#### ⚠️ Notas

* Esta versão estabelece **estrutura e convenções**, não estabilidade.
* Mudanças quebráveis são esperadas até o `1.0.0`.
* Versionamento ainda pode ser ajustado conforme o fluxo real de releases.
