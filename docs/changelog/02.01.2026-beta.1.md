## CHANGELOG

### 02.01.2026-beta.1 — Debug in auth and api 

## 🛠️ Funcionalidades

#### Auth
- Adicionado suporte multilíngue ao sistema de autenticação: ["pt", "en", "es"].
- Componentes Signin, Signup e Session atualizados com traduções.
- Melhorias no gerenciamento da sessão do usuário e nos rótulos da UI para maior acessibilidade.
- Mensagens de validação dos formulários agora suportam os novos idiomas.

#### API
- Atualizado o plugin `better-auth.ts`:
  - Corrigido o uso do tipo `Request`: substituído `req.headers` por tipagem adequada para evitar erro TS2339 no deploy.
- Integração aprimorada com o sistema de autenticação multilíngue.
- Melhor tratamento de erros e feedback nas respostas das rotas de autenticação.

### 🐛 Correções

- Corrigido erro TypeScript em `better-auth.ts`:
  ```text
  Property 'headers' does not exist on type 'Request'.
````

* Pequenos ajustes em rotas de API relacionados ao callback de auth e gerenciamento de sessão.
